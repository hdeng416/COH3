# 属性配置（Essence Editor）

脚本只负责三件事：无限升星、切换武器、脱战回血。
单位本身，包括单人小队、血量、两把武器和切换能力按钮，都要在 Essence Editor 的属性里做。
下面的字段名以你编辑器里实际显示的为准。思路是**复制一个原版单位再改**，不要从零建。

> 英雄连3 没有真正的近战（拼刺刀、肉搏）系统。
> “强力近战突击武器”在这里指**近距离伤害极高、远距离很弱**的武器，例如强化版冲锋枪或霰弹枪。

## 1. 小队 (Squad / sbp)

复制一个步兵小队，比如任意阵营的突击步兵，改名为 `hero_sbp`（要和脚本 `HERO_CONFIG.squad_blueprint` 一致）。

- **小队配置 (squad loadout)**：只保留 1 个成员，数量设为 1。
- **老兵 (veterancy)**：保留原版 3 级，给每级正常的加成。3 星以后的升星由脚本接管。
- **能力 (abilities)**：加入第 4 步的 `hero_weapon_switch_abp`。
- **造价 / 人口 / 生产上限**：英雄建议限制同时只能有 1 个，也就是把生产上限设为 1。
- **UI**：改名字、图标、描述，比如“英雄”。

## 2. 实体 (Entity / ebp)

复制小队里那个士兵的实体，改名为 `hero_ebp`，然后在小队配置里指向它。

- **生命值**：单人小队要扛得住，建议是普通步兵的 4 到 6 倍。
- **护甲 / 目标类型**：可以按“重步兵”处理。
- **武器挂点 (hardpoints)**：
  - `hardpoint_01`：突击武器，装冲锋枪还是霰弹枪由你决定
  - `hardpoint_02`：火箭筒

  挂点要和脚本 `HERO_CONFIG.weapons` 列表一一对应。每个挂点都要装上武器，脚本出生时只留一把开着。
  想三把轮换（比如冲锋枪、霰弹枪、火箭筒），就加一个 `hardpoint_03`，再在 `weapons` 里加一行。

## 3. 武器 (Weapon / wbp)

| 蓝图 | 从哪个复制 | 建议改法 |
| --- | --- | --- |
| `hero_assault_wbp` | 冲锋枪或霰弹枪，任选一把 | 近距离伤害、精度大幅提高，远距离衰减严重，射程短（约 15 到 20） |
| `hero_rocket_wbp` | 巴祖卡或反坦克火箭筒 | 伤害、穿深提高，装填缩短，可以加一点溅射用来打步兵 |

## 4. 切换武器能力 (Ability / abp)

复制任意一个**瞬发、无目标**的能力，改名为 `hero_weapon_switch_abp`（和脚本 `HERO_CONFIG.switch_ability` 一致）。

- 删掉所有动作 (actions)，只保留一个空能力。真正切换武器的是脚本。
- 冷却 3 到 5 秒，防止连点。
- 不消耗弹药或人力。
- 图标和描述写“切换突击武器 / 火箭筒”。

## 5. 放进生产列表

在你想要的生产建筑（比如总部）的生产列表 (spawn items) 里加上 `hero_sbp`。

## 6. 只用属性、不用脚本的替代做法

如果只想做一个 Tuning Pack（调参包，不能跑脚本），各项功能可以这样退而求其次：

- **升星**：只能做原版上限的老兵等级，给每级加大加成，做不到“无限”。
- **回血**：给实体加一个常驻的缓慢回血修正，但做不到“只在脱战后回血”。
- **切换武器**：需要用“升级 (upgrade) + 武器挂点条件”的方式实现。原版有些单位就是这样切换武器的，可以找一个来照抄。
